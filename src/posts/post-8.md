Here is a list of tools and services that power this site.

-  **[GitHub Pages](https://pages.github.com/)** for free hosting
-  **[Eleventy (11ty)](https://www.11ty.dev/)** for static site generation
-  **[GoatCounter](https://www.goatcounter.com/)** for lightweight, privacy-friendly analytics — no cookies, no tracking, just a rough sense of what people read
-  **[giscus](https://giscus.app/)** for comments, backed by GitHub Discussions
-  **[KaTeX](https://katex.org/)** for math rendering
-  **WebGL2 shaders written by hand** for the live contour map behind every page (open *ground.frag* at the bottom-left to edit it), the image slides and the editable demos
-  **[eleventy-img](https://www.11ty.dev/docs/plugins/image/)** for responsive, optimized images
-  **[Three.js](https://threejs.org/)** + **[GSAP](https://gsap.com/)** for the interactive 3D landing (loaded only on that page)
-  **Mostly vanilla HTML and CSS**
-  **[GitHub Actions](https://github.com/features/actions)** for CI/CD
